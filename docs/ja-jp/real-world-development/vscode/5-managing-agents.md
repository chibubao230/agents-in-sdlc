GitHub Copilot をエージェントモードで使うと、コードベースの調査、変更の提案、ファイル編集、コマンド実行などを自律的に行います。VS Code の Copilot Chat では、ローカルでリアルタイムに行われる作業を、各ツール呼び出しやファイル編集ごとに確認できます。差分をインラインでレビューし、変更を個別に承認または取り消し、追加のプロンプトで会話を方向付けて、エディターを離れずに作業を改善、拡張できます。

この演習では、次の内容を学習します。

- アクセシビリティエージェントの作業をリアルタイムに監視します。
- 提案されたファイル編集をレビューして承認します。
- セッション中にエージェントを方向付け、ハイコントラストに加えてライトモードの切り替えを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ用カスタムエージェントが、ハイコントラストモードを実装しています。作業中にデザインチームから追加の依頼がありました。既定のテーマを暗すぎると感じるユーザー向けに、ライトモードの切り替えも追加します。新しい会話を最初から始めるのではなく、現在のセッションを方向付けて作業を拡張します。

## Copilot の進捗を監視する

Copilot Chat ビューには、エージェントが実行する手順、調査するファイル、実行するコマンド、提案する編集が表示されます。ファイル編集はそれぞれ、差分と **Keep** / **Undo** 操作としてチャット内に表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中はチャットをスクロールし、各ツール呼び出しを確認します。ファイルの読み取りや編集、実行を求めるターミナルコマンドが表示されます。
3. エージェントがファイル編集を提案すると、差分がチャット内に表示されます。
   - **Keep** を選択すると変更を承認します。
   - **Undo** を選択すると変更を取り消し、エージェントにもう一度作業させます。
4. チャット上部の **Files changed** を開くと、このセッション中にエージェントが変更したファイル一式を確認できます。

> [!NOTE]
> ターミナルコマンドの実行などでツール呼び出しに許可が必要な場合、エージェントは一時停止し、**Allow** を求めます。実行して問題ないコマンドだけを許可してください。

5. エージェントがハイコントラストモードを実装し終えるまで待ちます。変更の概要をまとめたメッセージが表示されます。

## エージェントにライトモードを追加するよう依頼する

ハイコントラストモードができたので、同じ会話でライトモードの切り替えを追加します。同じチャットセッションを続けると、エージェントは前の作業のコンテキスト、変更したコンポーネント、スタイル設定、local storage の使用方法を保持しています。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントは既存の変更を調査し、ライトモードの追加を提案します。
3. 新しい編集が提案されるたびに、ハイコントラストモードと同じようにレビューします。各差分で **Keep** または **Undo** を選択します。
4. エージェントの進め方が希望と異なる場合 (たとえば、切り替え UI のリファクタリングが意図と違う場合) は、チャット入力欄の横にある **Stop** ボタンで停止し、意図を明確にする追加メッセージを送ります。

> [!TIP]
> 進行中のセッションを方向付ける方が、最初からやり直すより速く作業できます。追加プロンプトで、調整 ("CSS を簡素化し、セレクターを重複させず CSS 変数を使う")、方向修正 ("3 つ目の切り替えを増やさず、既存の設定パネルにライトモードを統合する")、範囲拡張 ("両方の切り替えにキーボードショートカットも追加する") を依頼できます。

## 変更内容を確認する

コミットする前に、エージェントが変更した内容を確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストが更新されているはずです。
3. 変更ファイルをいくつか開き、差分を確認します。カスタムエージェントのアクセシビリティパターン (ARIA 属性、キーボード操作、セマンティック HTML、local storage による永続化) が反映されていることを確認します。
4. 問題がなければ、Source Control パネルで変更をステージし、コミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェントモードを使って、進行中のセッションを監視し、方向付けました。ファイル編集ごとに確認し、変更を承認または取り消し、コンテキストを保持したまま追加のプロンプトを送り、作業を拡張しました。

この演習では、次の内容を学習しました。

- エージェントの作業をリアルタイムで監視する。
- 個々のファイル編集を承認または取り消す。
- 追加プロンプトを使って、進行中のセッションを方向付ける。
