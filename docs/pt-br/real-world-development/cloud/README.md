O **[agente de nuvem do GitHub Copilot](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** permite que o GitHub Copilot trabalhe de forma assíncrona na nuvem. Você atribui o trabalho no GitHub e o agente de nuvem o executa em segundo plano — explorando o repositório, fazendo alterações e abrindo um pull request — enquanto você se dedica a outras tarefas.

Nestes exercícios, você adicionará instruções personalizadas que o agente de nuvem seguirá e, em seguida, atribuirá um problema do GitHub para que ele implemente o trabalho. Você revisará o resultado e usará agentes personalizados para orientar a abordagem, acompanhará e direcionará sessões pelo painel de agentes e concluirá revisando os pull requests e iterando sobre os resultados.

## Pré-requisitos

Antes de participar deste workshop, verifique se você tem:

- [ ] Uma conta do GitHub com um plano ativo **Copilot Student, Pro, Pro+, Business ou Enterprise**
- [ ] O agente de nuvem do Copilot habilitado para sua conta ou organização

> [!TIP]
> Não tem um plano pago? Estudantes com situação verificada podem obter o GitHub Copilot gratuitamente pelo [GitHub Education][callout-student-plan-education]. O plano **Copilot Student** inclui o agente, MCP, revisão de código e recursos do Copilot CLI usados neste workshop — permitindo concluir todos os módulos com ele.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> O agente de nuvem está disponível nos planos **Copilot Student, Pro, Pro+, Business e Enterprise** — todos, exceto o Copilot Free. No Copilot Business ou Enterprise, um administrador precisa habilitar o recurso para a organização.

> [!NOTE]
> Este módulo não aborda MCP. Para explorar o uso de servidores MCP com o Copilot, consulte o [módulo do CLI][cli] ou o [módulo do VS Code][vscode].
